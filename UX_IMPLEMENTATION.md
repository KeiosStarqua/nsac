## Honest limitations
- Everything on `/sky` is **simulated**: no real sensors, no clinical validation, no NASA/SpaceX certification.
- The LLM composes panels only in `/`, `/concept`, `/demo`, `/story` (OpenUI path). `/sky` uses a deterministic planner; scenes pass the same `validateScene` gate but no model currently authors them.
- Earth uplink is a client timer, not the SQLite `outbox` (that lives in the Python backend and is used by the `/demo`-style backend flow only via the CLI).
- No persistent action log / audit on the web client.
- Devices beyond the 12 listed render fallbacks by construction; `sensor`/`ar`/`audio` are surfaces, not working hardware paths.
- No end-to-end browser tests; verification is typecheck + unit tests + manual smoke + live curl.
