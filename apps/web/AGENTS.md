## Purpose

Web app for **Sky**, the clinical assistant for astronauts and flight surgeons. Routes: `/` — the **Hub Gen console** ("SKY · Astronaut Wellness", `features/hud-gen/`; the only console since the Hub Mock was removed 2026-11-17, `routes/index.tsx` renders `<SkyScreenGen />` unconditionally with `ssr: true` and no search schema): three-column simulated dashboard — astronaut profile + vital signs + quick trends / orb + greeting + voice / overall readiness with four detail tabs + three mini metric cards + one deterministic insight band to `/performance` — with its whole display tree declared as an OpenUI Lang program (preset, then the `sky-hud-composer` agent program); see its own bullets below with the astronaut picker (`features/astronaut/`, picked id saved in localStorage `nsac.astronaut`, claim-locked through the backend `/api/claims` with an anonymous session in localStorage `nsac.session` — one session holds one crew member, unreachable backend ⇒ local pick still works and claims are simply not enforced; claims tự giải phóng sau 30 phút idle (heartbeat mỗi 30 s khi tab visible qua `useClaimHeartbeat` + `POST /api/claims/heartbeat`; sweep lười trong `list`/`claim`/`heartbeat` + interval 60 s backend, `SKY_CLAIM_TTL_MINUTES` override);
